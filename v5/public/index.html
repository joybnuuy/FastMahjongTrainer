속성 마작 연습

실제 천봉 봉황방 대국에서 뽑은 장면으로 연습합니다. 채점하는 Mortal AI는 이 기기 안에서 돌아가며, 서버가 필요 없습니다.

설정이 끝나 있어서 바로 이동합니다…

① 엔진 (Mortal 모델)

AI 모델 파일을 이 기기에 내려받습니다. 엔진이 여러 개면 하나를 골라 쓰고, 안 쓰는 엔진은 지울 수 있습니다. 실행 프로그램(약 15MB)은 모든 엔진이 함께 쓰며 브라우저 캐시에 저장됩니다.

② 데이터 저장소

연습에 쓸 대국 로그가 있는 폴더 주소입니다 (manifest.json이 있는 https 주소). 이 주소는 이 브라우저에만 저장됩니다.

저장소가 없다면 로그 파일(.xml)만 직접 불러서 쓰기 — 화면 안의 ⚙ 설정에서 파일을 가져옵니다.

③ 화면

두 화면은 기능이 같습니다 (이론 해설, 위험패 찾기, 오답노트). 고르기만 하고 이동하지는 않습니다. 나중에 ⚙ 설정에서 바꿀 수 있습니다.

저장 공간 관리 (지우기)

엔진은 위 ① 카드에서 하나씩 삭제합니다. 오답노트는 아래 어떤 항목으로도 지워지지 않습니다.

  • 로그 캐시: 내려받아 둔 대국 로그(저장소 주소는 유지, 다시 받으면 됨)
  • 설정 초기화: 저장소 주소·화면·엔진 선택·설치 기록 (내려받은 파일은 그대로)
  • 모두 지우기: 모든 엔진 + 로그 캐시 + 설정

이 메뉴는 화면 안의 ⚙ 설정 → 메인 메뉴로 다시 열 수 있습니다.
